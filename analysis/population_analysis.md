# Nigeria Population Distribution Analysis

## 1. Introduction

This analysis examines the spatial distribution of estimated population across Nigeria's 36 states and the Federal Capital Territory.

The analysis was conducted using QGIS and state-level population estimates from WorldPop.

## 2. Purpose

The purpose of this analysis is to identify broad differences in estimated population among Nigerian states and describe the spatial patterns displayed on the thematic map.

## 3. Data and Method

The analysis used:

- Nigeria's first-level administrative boundaries.
- State-level population estimates from WorldPop.
- A joined vector layer containing state boundaries and population values.
- Graduated symbology to represent population differences.

The population data was joined to the administrative boundaries using standardized state names.

## 4. Observed Population Patterns

After examining the completed map, the following observations should be recorded:

### States with relatively high population values

- State 1: Kano State
- State 2: Ogun State
- State 3: Lagos State

### States with relatively low population values

- State 1: Bayelsa State
- State 2: Cross River State
- State 3: Ebonyi State

### General spatial pattern

The map shows that relatively high estimated population values are concentrated in selected parts of northern Nigeria, particularly around Kano and Kaduna. Niger also displays a relatively high population value compared with several surrounding states.

In southern Nigeria, Ogun stands out as a state with a relatively high estimated population value. However, higher population values are not restricted to one specific region, as some southern and central states also show moderate-to-high values.

Relatively low population values appear across several states in the central, southeastern, and northeastern parts of the country. Overall, the map indicates considerable variation in estimated population among Nigerian states rather than a uniform north–south pattern.

## 5. Interpretation

The map illustrates differences in estimated population between states. However, state-level population figures do not explain the distribution of people within each state.

Factors such as urbanization, employment opportunities, infrastructure, historical settlement patterns, and environmental conditions may influence population distribution. These factors were not directly analyzed in this project.

## 6. Limitations

- The population values are estimates and may differ from official census figures.
- The analysis is conducted at the state level.
- The map does not show population density.
- The analysis does not establish the causes of population differences.

## 7. Conclusion

The project demonstrates how GIS can be used to combine administrative boundaries with population data and communicate geographic patterns through thematic mapping.

Further analysis could examine population density, urban growth, or population change over time.
